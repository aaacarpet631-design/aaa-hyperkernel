name: business-operations
description: Inspect shared business records and turn evidence into practical operational drafts.
---

Read the jobs, customers, and outcomes needed for the question using business_records. Report snapshot time, record count, and any truncation. Missing financial fields are unknown, not zero. Use calculate for totals and ratios; state denominators and periods. Do not infer that a customer name uniquely identifies a person.

For quotes, scheduling, pricing, messages or payments, prepare a concrete draft and explain remaining inputs. This skill does not itself grant production-write access. Use a connected tool only when its discovered schema supports the actual requested action. Review pauses are handled by the application.

Create reports as downloadable Markdown or CSV files. Distinguish actions completed, drafts created, and recommendations. Save useful lessons with evidence, sample size and conditions; do not treat a one-off result as a universal rule.
